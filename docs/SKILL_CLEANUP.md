# Skill Cleanup Procedure

## Desired result
Keep these project skills:
- `.agents/skills/hallmark/`
- `.agents/skills/civictech-implementation/`

Remove these overlapping skills if the folders shown in the current repository still exist:
- `.agents/skills/design-taste-frontend/`
- `.agents/skills/redesign-existing-projects/`

Do not remove Hallmark's `references/` folder. Do not delete unrelated installed skills outside this repository.

## Before deletion
1. Make sure the repository is open at its root.
2. Check Git status.
3. Confirm the two target folders are exactly the overlapping skill folders.
4. Keep a backup/commit if you want a reversible cleanup.
5. Inspect `skills-lock.json` and determine whether it is generated by the skill CLI.

## PowerShell commands (run from repository root)
```powershell
git status --short
Test-Path ".agents/skills/design-taste-frontend"
Test-Path ".agents/skills/redesign-existing-projects"
```

Only if both paths are the intended folders:
```powershell
Remove-Item -Recurse -Force ".agents/skills/design-taste-frontend"
Remove-Item -Recurse -Force ".agents/skills/redesign-existing-projects"
```

## Git Bash equivalent
```bash
git status --short
test -d .agents/skills/design-taste-frontend && echo "design skill exists"
test -d .agents/skills/redesign-existing-projects && echo "redesign skill exists"
```

Only if confirmed:
```bash
rm -rf .agents/skills/design-taste-frontend
rm -rf .agents/skills/redesign-existing-projects
```

## Lockfile
- Do not hand-edit the lockfile unless its format is understood.
- Prefer the same skills CLI used to install the skills to update/remove lock entries.
- If it is a generated manifest and no CLI removal command exists, inspect its schema and remove only stale entries.
- Run `git diff -- .agents/skills skills-lock.json` after cleanup.
- Confirm Hallmark and the CivicTech skill still exist.
- Never remove `.agents/skills/hallmark/` or its references as part of this cleanup.

## Verification
- Reopen the project in Antigravity if skill discovery appears cached.
- Confirm Hallmark instructions can be read.
- Confirm the CivicTech skill is discoverable.
- Do not claim that a skill was activated or used unless the agent actually read it.
